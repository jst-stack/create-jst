# create-jst

Create a web application from the [JST](https://github.com/jst-stack/jst) template.

```bash
npm create jst@latest my-app
```

The command downloads the template without its Git history, configures its application metadata, optionally removes the demo domain, installs dependencies, and creates a new Git repository.

```bash
npm create jst@latest my-app -- --yes
```

Use `--help` to view non-interactive options.
